# 🤝 3_Areas — Kolaborasi

Area tanggung jawab berkelanjutan untuk **proses tim & kolaborasi** FinTrack v2.

## Scope

- Proses kerja & alur kontribusi.
- Konvensi commit & git workflow.
- Code review & kepemilikan modul.
- Ceremonies (perencanaan sprint, review, retrospektif).

## Dokumen

| Dokumen | Isi |
|---|---|
| `WORKFLOW.md` | Proses kerja & git workflow |
| `CODE_REVIEW.md` | Alur & tanggung jawab review |

## Prinsip

1. **Fase sequential** — fase berikut tidak mulai sebelum DoD fase sebelumnya terpenuhi.
2. **Satu penulis per file** saat paralel; koordinasi sebelum mengedit bersama.
3. **Commit atomik & deskriptif** — satu perubahan logis per commit.
4. **Review wajib** untuk perubahan sensitif (billing, keamanan, migrasi).
